# zhangjs0303.github.io

A static academic homepage with a retro Frutiger Aero city-future visual direction.

## Publishing

1. Upload `index.html`, `styles.css`, and the complete `assets/` folder to the repository root.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder.
4. Visit <https://zhangjs0303.github.io> after the deployment finishes.

## Page content

The page includes Junshuo Zhang's public GitHub profile, the research direction “Neural dynamics as a sampling,” and contact links. The visual system combines a glass-water Aero cityscape, a glass sphere, glossy highlights, and translucent glass panels.
