# zhangjs0303.github.io

这是一个可直接发布到 GitHub Pages 的静态学术主页，当前视觉方向为复古 Frutiger Aero 城市未来感。

## 发布

1. 在 GitHub 新建公开仓库：`zhangjs0303.github.io`。
2. 把 `index.html`、`styles.css` 和整个 `assets/` 文件夹上传到仓库根目录。`assets/` 中包含主页使用的生成素材，不能漏传。
3. 进入 **Settings → Pages**，选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。
4. 等待几分钟后访问 <https://zhangjs0303.github.io>。

## 当前页面内容

页面已根据 GitHub 公开资料放入 `Junshuo Zhang`、GitHub 主页，以及当前研究方向 `Neural dynamics as a sampling`。主视觉使用蓝天、玻璃城市、水面、绿色丘陵、透明气泡和 Aero 光带等元素，内容区使用透明玻璃窗口。

## 建议补充的内容

- `index.html` 中的研究方向卡片
